## 一、整体流程

脚本分两大块：

1. **定位方块识别** —— 在画面里找出 4 个"二维码角块"样式的方块
2. **卡片放置格子定位** —— 用这 4 个方块算出玩家区的透视变换，再按比例切 **7 列 × 3 行** 网格

```
输入图像 (BGR)
    ↓
【定位方块识别】
    ① 灰度化 + CLAHE（压制反光）
    ② HSV 阈值 + 灰度阈值 → 白色掩膜
    ③ 闭运算（连接内部破碎）+ 腐蚀（分离粘连）
    ④ 找轮廓 + 六重过滤（尺寸按比例）
    ⑤ 象限筛选（每象限 1 个）→ 4 个方块
    ↓
【格子定位】
    ⑥ 4 角分配（含 2/3 点推算）
    ⑦ 透视变换 H（画面 → 正空间 0~1）
    ⑧ 正空间里按 7 列 × 3 行 均匀切网格
    ⑨ 点击位置 → H 映射 → 查格子
    ↓
输出：Player1 | 类型 | 第 N 号 (行 R 列 C)
```

## 二、横板 vs 竖板的区别

| 项 | 竖板（`regiontest.py`） | 横板（`h_regiontest.py`） |
|----|------------------------|-------------------------|
| **网格** | 7 行 × 3 列 | **3 行 × 7 列** |
| **玩家区宽高比** | 宽 < 高（0.42） | **宽 > 高（2.2）** |
| **方块尺寸范围** | 40~70（绝对像素） | **4%~10%（占 ROI 宽度比例）** |
| **白占比上限** | 0.90 | **0.85** |
| **内部黑下限** | 0.01 | **0.0（关闭）** |
| **腐蚀核** | 3 | **5** |
| **布局** | 纵向 7 行 | 横向 7 列 |

**横板布局**（7 列 × 3 行）：

```
         列1    列2    列3    列4    列5    列6    列7
行1:     -      -     EX1     -     EX2     -      -
行2:    场地   前场1  前场2  前场3  前场4  前场5  墓地
行3:    额外   后场1  后场2  后场3  后场4  后场5  卡组
```

## 三、定位方块识别

### 目标

玩家区有 **4 个定位方块**，分布在**玩家区的 4 个角**。识别到它们后，**4 个方块的外包围区域**就是玩家区的边界。

**定位方块外观**：

- 正方形，边长**占 ROI 宽的 4%~10%**
- 白边 + 中间黑（实心版：外白框 + 黑心 + 内白点；空心版：只有白边框）
- **边缘是白**（不是黑）

### 步骤

#### 第 1 步：灰度化 + CLAHE 增强

```python
gray = cv2.cvtColor(sub, cv2.COLOR_BGR2GRAY)
clahe = cv2.createCLAHE(clipLimit=4.0, tileGridSize=(8, 8))
gray_c = clahe.apply(gray)
```

- **灰度化**：3 通道压成 1 通道，减少计算量
- **CLAHE**：把图像分成 8×8 小块，每块独立做直方图均衡
- **`clipLimit=4.0`**（比默认 2.0 大）：**专门压制屏幕反光的过曝区**

#### 第 2 步：提取白色掩膜

```python
hsv = cv2.cvtColor(sub, cv2.COLOR_BGR2HSV)
mask_hsv = cv2.inRange(hsv, (0, 0, 120), (180, 160, 255))
_, mask_gray = cv2.threshold(gray_c, 180, 255, cv2.THRESH_BINARY)
mask_white = cv2.bitwise_and(mask_hsv, mask_gray)
```

- **HSV 条件**：H 任意、S ≤ 160（低饱和）、V ≥ 120（高亮度）→ 灰白色
- **灰度条件**：CLAHE 后灰度 ≥ 180 → 亮
- **交集**：同时满足"低饱和 + 高亮度" → 真正白色
- **排除**：彩色反光（S 高）、暗背景（V 低）

#### 第 3 步：闭运算（连接破碎区域）

```python
kernel_close = np.ones((3, 3), np.uint8)
mask_closed = cv2.morphologyEx(mask_white, cv2.MORPH_CLOSE,
                               kernel_close, iterations=1)
```

**闭运算 = 先膨胀后腐蚀**。

- **目的**：把方块内部的"外白框 + 内白点"（原本独立）**连成一块**
- **为什么 3×3 迭代 1**：膨胀 1px + 腐蚀 1px → **够连间隙 2px 的白块**，但不会把相邻方块（间隙 > 10px）粘一起

#### 第 4 步：腐蚀（分离粘连）

```python
kernel_erode = np.ones((5, 5), np.uint8)   # ★ 横板：从 3×3 加大到 5×5
mask_closed = cv2.erode(mask_closed, kernel_erode, iterations=1)
```

- **目的**：反光可能让相邻方块或方块和卡图**粘连成一块**。腐蚀一次让它们**缩回独立**
- **横板为什么要 5×5**：横板下反光更强，方块和反光块容易粘连，需要更大的腐蚀核

#### 第 5 步：找轮廓

```python
contours, _ = cv2.findContours(mask_closed, cv2.RETR_EXTERNAL,
                               cv2.CHAIN_APPROX_SIMPLE)
```

- **`RETR_EXTERNAL`**：只找最外层轮廓
- **`CHAIN_APPROX_SIMPLE`**：压缩轮廓点

#### 第 6 步：逐轮廓六重过滤

| # | 过滤 | 阈值 | 目的 |
|---|------|------|------|
| 1 | **边长** | **ROI 宽的 4%~10%** | 过滤格子框、噪点、反光块 |
| 2 | **宽高比** | 0.75~1.35 | 过滤细长形状 |
| 3 | **四边形 + 凸** | 4 顶点 + 凸 | 过滤箭头/圆形/不规则 |
| 4 | **白占比** | 0.05~0.85 | 允许空心框 & 实心方块，过滤纯白反光 |
| 5 | **内部黑** | 关闭（`INNER_BLACK_MIN=0.0`） | 横板下方块可能是实心白块 |
| 6 | **灰度 std** | ≥ 15 | 排除纯白反光 |

**为什么边长改用"比例"**：

```python
roi_w = rx1 - rx0
side_min = int(roi_w * SIDE_MIN_RATIO)   # 0.04
side_max = int(roi_w * SIDE_MAX_RATIO)   # 0.10
```

**图片缩小/放大后**，方块尺寸同比例缩放 → **比例不变** → 都能检出。**用绝对像素会因缩放而失效**。

**为什么 `WHITE_RATIO_MAX=0.85`**：

- **反光块**：纯白 → `wr ≈ 0.9~1.0` → **被 0.85 过滤**
- **实心白方块**：`wr ≈ 0.5~0.8` → **通过**
- **空心白框**：`wr ≈ 0.05~0.15` → **通过**

**为什么 `INNER_BLACK_MIN=0.0`**：

- **横板下方块可能是"实心白块"**（内部无黑心）→ `inner_black ≈ 0`
- **用 `INNER_BLACK_MIN=0.05` 会把实心白块过滤**
- 所以**关闭内部黑约束**，改用 `WHITE_RATIO_MAX=0.85` 过滤反光块

#### 第 7 步：象限筛选

```python
def filter_by_quadrant(marks, rect):
    """每个象限只保留 1 个最靠角的方块。"""
```

把 ROI 分成 2×2 象限：

```
┌─────────┬─────────┐
│   tl    │   tr    │
├─────────┼─────────┤
│   bl    │   br    │
└─────────┴─────────┘
```

**每象限只保留"离该象限角最近"的 1 个方块** → 防止多候选落在同一象限 → 保证共 4 个。

## 四、卡片放置格子定位

### 第 1 步：4 角分配

```python
def assign_corners(marks, roi_x0=0, roi_x1=None):
```

4 个方块按位置分配到 `tl / tr / br / bl`：

| 情况 | 处理 |
|------|------|
| **4 个方块** | 按 x/y 中位数分四象限 |
| **3 个方块** | 同上，缺 1 个 |
| **2 个方块同行** | 用 `PLAYER_AREA_W_H_RATIO` 往下推 |
| **2 个方块同列** | 同上，往右推 |
| **2 个对角** | 无法推算，报错 |
| **< 2 个** | 报错 |

**2 点同行的推算**（横板下最常见）：

```python
player_w = right_pt['cx'] - left_pt['cx']
player_h = player_w / PLAYER_AREA_W_H_RATIO   # 2.2
corners['bl'] = {'cx': left_pt['cx'], 'cy': left_pt['cy'] + player_h, ...}
corners['br'] = {'cx': right_pt['cx'], 'cy': right_pt['cy'] + player_h, ...}
```

**`PLAYER_AREA_W_H_RATIO = 2.2`**：玩家区宽/高比。

- **横板**：宽 > 高 → **2.2**（从截图量：左 920px / 高 420px ≈ 2.2）
- **竖板**：宽 < 高 → 0.42

### 第 2 步：用平行四边形约束推缺失角

4 个方块构成平行四边形，对角线中点相同：

```
TL + BR = TR + BL
```

缺一个角时：

```
missing = other1 + other2 - opposite
```

**例**：缺 BR，已知 TL、TR、BL：

```
BR = TR + BL - TL
```

**这个公式对透视投影也近似成立**。

### 第 3 步：透视变换（Homography）

```python
src = np.float32([tl, tr, br, bl])          # 画面上的 4 个角
r = SRC_CORNER_RATIO                         # 0.043
dst = np.float32([[r, r], [1-r, r], [1-r, 1-r], [r, 1-r]])
H = cv2.getPerspectiveTransform(src, dst)
inv_H = cv2.getPerspectiveTransform(dst, src)
```

**核心**：用 H 矩阵把画面坐标 → 正空间（0~1）。正空间里玩家区是标准矩形。

**`SRC_CORNER_RATIO = 0.043`**：

- 4 个方块在玩家区的 4 个角，但**方块本身有大小**
- **方块中心 ≠ 玩家区边缘**
- 从截图量：方块高 46px / 玩家区高 537px → 23/537 ≈ 0.043
- 所以 4 个方块在正空间的 `(0.043, 0.043)`、`(0.957, 0.043)`、`(0.957, 0.957)`、`(0.043, 0.957)`

### 第 4 步：正空间切 7 列 × 3 行

```python
x0, x1 = r, 1 - r       # 0.043 ~ 0.957
y0, y1 = r, 1 - r
cell_w = (x1 - x0) / 7  # ★ 7 列
cell_h = (y1 - y0) / 3  # ★ 3 行
```

**网格范围 `[r, 1-r]`**，避开方块本身。

**布局定义**：

```python
H_LAYOUT = [
    (1, 3, "EX", 1),           # 行 1：EX 区
    (1, 5, "EX", 2),
    (2, 1, "场地魔法", None),   # 行 2：前场 + 场地 + 墓地
    (2, 2, "前场", 1),
    ...
    (3, 1, "额外卡组", None),   # 行 3：后场 + 额外 + 卡组
    (3, 2, "后场", 1),
    ...
]
```

每个格子写明 `(row, col, 类型, 编号)`。

### 第 5 步：判断点击位置

```python
# 1. 映射到正空间
norm = cv2.perspectiveTransform(np.array([[[px, py]]], np.float32), H)
nx, ny = norm[0, 0]

# 2. 检查是否在 0~1 范围内
if 0 <= nx <= 1 and 0 <= ny <= 1:
    # 3. 查哪个格子包含 (nx, ny)
    for region in regions:
        if region['x0'] <= nx <= region['x1'] and \
           region['y0'] <= ny <= region['y1']:
            return region
```

**输出**：`Player1 | 前场 | 第 2 号 (行 2 列 3)`

## 五、为什么这套算法鲁棒

### 定位方块识别

| 挑战 | 应对 |
|------|------|
| 屏幕反光 | CLAHE clipLimit=4.0 压制过曝；`std ≥ 15` 排除纯白 |
| 反光块误检 | `WHITE_RATIO_MAX=0.85` 过滤纯白块；`SIDE_MAX_RATIO=0.10` 过滤大反光块 |
| 空心框/实心框/二维码角块混用 | `WHITE_RATIO ∈ [0.05, 0.85]`；`INNER_BLACK_MIN=0.0` 关闭黑心约束 |
| 方块粘连 | 腐蚀核 5×5 分离 |
| 多候选项 | 象限筛选，每象限 1 个 |
| **图片缩放** | **边长按 ROI 宽度比例（4%~10%），不依赖绝对像素** |

### 格子定位

| 挑战 | 应对 |
|------|------|
| 画面旋转/透视 | 用 4 个方块算 Homography，把歪四边形拉正 |
| 只检出 3 个方块 | 平行四边形约束推第 4 个 |
| 只检出 2 个方块 | 用 `PLAYER_AREA_W_H_RATIO=2.2` 推算另一行 |
| 方块中心 ≠ 玩家区边缘 | `SRC_CORNER_RATIO=0.043` 补偿 |

## 六、关键参数说明

| 参数 | 值 | 含义 |
|------|-----|------|
| `WHITE_MIN_V` | 120 | HSV V 通道下限（白色亮度） |
| `WHITE_MAX_S` | 160 | HSV S 通道上限（允许偏色） |
| `CLAHE_CLIP` | 4.0 | CLAHE 对比度限制（压制反光） |
| `SIDE_MIN_RATIO` | **0.04** | 方块最小边长 = ROI 宽的 4% |
| `SIDE_MAX_RATIO` | **0.10** | 方块最大边长 = ROI 宽的 10% |
| `SQUARE_MIN/MAX` | 0.75 / 1.35 | 宽高比范围（正方形） |
| `WHITE_RATIO_MIN/MAX` | 0.05 / **0.85** | 白像素占比范围 |
| `INNER_BLACK_MIN` | **0.0** | 内部黑约束（关闭） |
| `STD_MIN` | 15 | 灰度标准差下限 |
| `ERODE_KERNEL` | **5** | 腐蚀核大小（比竖板大） |
| `PLAYER_AREA_W_H_RATIO` | **2.2** | 玩家区 宽/高 比（横板） |
| `SRC_CORNER_RATIO` | 0.043 | 定位方块在正空间里的内缩比例 |
| `GRID_ROWS/COLS` | **3 / 7** | 网格行数和列数（横板：3 行 7 列） |

## 七、数据流

```
输入图像 (BGR)
    ↓
① 灰度化 + CLAHE
    ↓
② HSV 阈值 + 灰度阈值 → mask_white
    ↓
③ 闭运算（连接内部破碎） + 腐蚀 5×5（分离粘连）
    ↓
④ 找轮廓
    ↓
对每个轮廓：
    边长 4%~10% ROI 宽？
    宽高比 0.75~1.35？
    四边形 + 凸？
    白占比 0.05~0.85？
    内部黑：关闭
    灰度 std ≥ 15？
    ↓
⑤ 象限筛选（每象限 1 个）
    ↓
4 个方块
    ↓
⑥ 4 角分配（含 2/3 点推算）
    ↓
⑦ 透视变换 H（画面 → 正空间）
    ↓
⑧ 在正空间按 7 列 × 3 行 切网格
    ↓
⑨ 点击 → H 映射 → 查格子
    ↓
输出：Player1 | 类型 | 第 N 号 (行 R 列 C)
```
